# Nutrient DWS MCP

The [local Nutrient DWS MCP server](https://github.com/PSPDFKit/nutrient-dws-mcp-server) bundled with this plugin is retired. Use the [hosted Nutrient plugin](https://github.com/PSPDFKit/nutrient-mcp-plugins#install) for new document-processing tasks. Follow the install instructions and sign in with your Nutrient account, then use the document workflow skill bundled with the hosted plugin.
